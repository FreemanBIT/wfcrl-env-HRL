WFCRL → FAST.Farm 场控指令信息流架构

Wind Farm Control RL
Continuous / Step-based Simulation

两种仿真模式

  • • Step模式: 每步重启 FAST.Farm 子进程，流场重置
  • • 连续模式: 一次启动，流场持续演化，DLL桥接控制
  • • FLORIS模式: Python API 直接调用，稳态尾流模型

5-Mode Farm Control Protocol

  • • mode=0: 纯偏航 (yaw delta)
  • • mode=1: 功率目标 + 最小变桨
  • • mode=2: 纯变桨绝对值
  • • mode=3/4: 组合控制 (pitch + yaw + power)

关键数据流

  • • RL Agent → ControlInput → Interface → File I/O
  • • controls.txt ↔ DISCON bridge DLL ↔ ServoDyn
  • • .outb / measurements_T*.txt → SimulationOutput
  • • SimulationOutput → state/reward → RL Agent
